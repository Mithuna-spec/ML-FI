# Resume Screening & Candidate Ranking System

## Overview
This project automatically screens and ranks resumes based on a given job description using NLP techniques.

## Features
- Resume text cleaning
- TF-IDF vectorization
- Cosine similarity scoring
- Candidate ranking
- Skill gap identification

## How It Works
Resumes are converted into numerical vectors and compared with the job description using cosine similarity. Higher score means better match.

## Business Use
- Faster candidate shortlisting
- Better skill matching
- Reduced recruiter workload
