# Sales & Demand Forecasting for Businesses

## Project Overview

This project predicts future sales using historical business data. Sales forecasting helps businesses plan inventory, manage staffing, improve budgeting, and avoid losses caused by overstocking or low stock.

This project uses the Superstore Sales Dataset and applies Machine Learning techniques to forecast future monthly sales.

---

## Objective

The main goal is to predict future sales based on past sales data and present the forecast in a business-friendly way.

---

## Tools Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- GitHub

---

## Dataset Used

Superstore Sales Dataset

Main columns used:
- Order Date
- Sales

---

## Steps Performed

1. Data Cleaning
2. Date Conversion
3. Monthly Sales Aggregation
4. Feature Engineering
5. Model Training using Linear Regression
6. Model Evaluation
7. Sales Forecast Visualization
8. Model Saving

---

## Model Used

Linear Regression

Features:
- Month
- Year
- Previous Month Sales
- Previous Two Month Sales

Target:
- Sales

---

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)

## Business Insights

- Future demand can be predicted using past trends
- Businesses can use forecasts for inventory planning and budgeting
