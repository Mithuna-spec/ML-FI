# Support Ticket Classification & Prioritization

## Overview
This project classifies customer support tickets into categories and assigns priority levels using NLP and Machine Learning.

## Objective
Automate ticket handling to improve response time and reduce manual effort.

## Features
- Text cleaning and preprocessing
- TF-IDF feature extraction
- Category classification
- Priority prediction
- Model evaluation

## Models Used
- Logistic Regression

## Results
The model predicts:
- Ticket Type (category)
- Ticket Priority (high, medium, low)

## Business Use
- Faster ticket routing
- Improved response time
- Reduced workload on support teams

## Output
- Trained models saved as model.pkl
